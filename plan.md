# Vina project plan

## Objective

Create a standalone, GitHub-ready Python project for protein structure search, selection, download, preparation, and AutoDock Vina docking.

## Modules

1. Search PDBe best experimental structures using UniProt IDs.
2. Rank candidates with transparent experimental-structure heuristics.
3. Download selected PDB structures from RCSB.
4. Prepare a reference-ligand-defined Box, receptor and ligands, then dock with Meeko and Vina.
5. Provide a public 1IEP example and environment definition.

## Exclusions

No OEKDTRANS target tables, experimental PDB files, docking outputs, credentials, or project-specific biological conclusions.
